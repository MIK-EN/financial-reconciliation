# Financial Reconciliation

Сервис сверки заказов, платежей и возвратов из файлов. Портфолио-проект Python backend.

Сейчас подготовлено только окружение разработки. Загрузка файлов, сверка, API и тесты бизнес-логики ещё не реализованы. Внешних платёжных интеграций нет.

## Окружение

Нужны Python 3.13 и uv 0.8.15. Версия uv совпадает с закреплённой в CI; системная установка не обновляется автоматически.

Из корня проекта:

```bash
uv sync --locked
uv run --locked python --version
uv run --locked python -c 'import reconciliation; print(reconciliation.__file__)'
```

uv создаёт `.venv` и устанавливает зависимости из `uv.lock`. Активация окружения для команд `uv run` не требуется. `pyproject.toml` описывает зависимости, `uv.lock` фиксирует разрешённые версии, включая транзитивные зависимости.

## Проверки

```bash
uv run --locked ruff check .
uv run --locked ruff format --check .
uv run --locked mypy src/reconciliation
```

Для локального форматирования: `uv run --locked ruff format .`. CI только проверяет код, не исправляет его.

pytest установлен для будущих тестов. Тестовых файлов пока нет, поэтому pytest не запускается в CI. Зелёные проверки на текущем этапе подтверждают корректность основы, а не финансовых расчётов.

## CI

GitHub Actions запускает установку из lock-файла и три проверки качества на Python 3.13 под Linux при push и pull request. Любая ошибка завершает job неуспешно. Секреты не требуются. Развёртывание пока не настроено.

Удалённый запуск CI возможен после публикации файлов в репозитории. Его состояние нужно проверять во вкладке Actions, отдельно от локальных проверок.
