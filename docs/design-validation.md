# Проверка проекта правил онбординга

Дата: 2026-11-11. Проверены документы и математические свойства предложенных правил; приложение ещё не реализовано. Это не результат тестов приложения или педагогической валидации.

## Подсчёт в согласованных текстах

- Упрощённый: 9 словоупотреблений, 8 уникальных; доступен при 0–1, трудный при 2–8. Проверены все 9 возможных количеств отметок.
- Стартовый: 15 словоупотреблений, 14 уникальных; доступен при 0–2, трудный при 3–14. Проверены все 15 возможных количеств отметок.
- Установка: 23 словоупотреблений, 20 уникальных; доступен при 0–4, трудный при 5–20. Проверены все 21 возможных количеств отметок.
- Параметры: 29 словоупотреблений, 26 уникальных; доступен при 0–5, трудный при 6–26. Проверены все 27 возможных количеств отметок.
- Ограничения: 34 словоупотреблений, 31 уникальных; доступен при 0–6, трудный при 7–31. Проверены все 32 возможных количеств отметок.

## Все конечные маршруты

- start (доступен) → installation (доступен) → parameters (доступен) → constraints (доступен) → complex_texts; причина constraints_accessible.
- start (доступен) → installation (доступен) → parameters (доступен) → constraints (трудный) → confident_reading; причина parameters_accessible.
- start (доступен) → installation (доступен) → parameters (трудный) → basic_docs; причина installation_accessible.
- start (доступен) → installation (трудный) → foundations; причина start_accessible.
- start (трудный) → simplified (доступен) → foundations; причина simplified_accessible.
- start (трудный) → simplified (трудный) → foundations; причина simplified_difficult.

## Граница и ограничения проверки

- Ровно 20% (4 из 20) относятся к доступному тексту; 5 из 20 — к трудному.
- Все маршруты завершаются за 2–4 текста; циклов и недостижимых рекомендаций нет.
- Проверка не исполняла продуктовый код: он ещё не написан. Транзакции, cookie, гонки, браузер и CI должны проверяться при реализации по docs/design.md.
- Не проверялись эффективность обучения и соответствие текстов CEFR; таких утверждений нет.

## Независимое ревью документа

Отдельный агент проверил docs/design.md, docs/onboarding-content.md, исходные границы и договор. Найдены два существенных замечания:

1. Повтор ответа предыдущего шага мог ошибочно проверяться по текущему тексту. Исправлено: длина и членство word_ids проверяются по переданному step_id и закреплённой версии. В критерии добавлен случай start с 10 неизвестными словами → simplified с N=8 → повтор исходного ответа.
2. Регистрация при действующей auth-сессии не имела явного поведения. Исправлено: 409 already_authenticated без изменений; сначала явный выход либо сохранение результата в текущий аккаунт.

После исправлений агент повторно проверил эти области: оба замечания устранены, новых существенных противоречий от изменений не найдено. Ревью подтверждает определённость документа для планирования; оно не заменяет будущие тесты реализации или пользовательское утверждение общего дизайна.
