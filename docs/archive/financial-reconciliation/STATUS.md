Решения об установленном uv 0.8.15, backend uv_build и текущей папке без нового worktree записаны в docs/decisions.md. Итоговое read-only ревью существенных замечаний не выявило.

Подтверждено дополнительное правило: несколько успешных платежей на один заказ; сравниваем их суммарную величину со стоимостью заказа. Обязателен payment_id: одинаковый ID и данные учитываются один раз, другая сумма или заказ при том же ID — конфликт. При конфликте ранее загруженный платёж не перезаписываем, конфликт сохраняем для разбора, затронутый заказ требует проверки. Детали конфликтов внутри первого файла и повторной обработки уточним в дизайне.

Согласован частичный импорт: корректные строки сохраняются, проблемные доступны в отчёте, исходный файл сохраняется. Ошибки всего файла останавливают импорт; ошибки строк не отменяют остальные строки. Сверка по неполным данным явно предупреждает об ограничении результата. Notion снова доступен; правило payment_id и частичный импорт сохранены в карточке требований.
