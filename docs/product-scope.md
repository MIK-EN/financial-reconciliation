# Английский для разработчиков

## Подтверждено пользователем

- Создаём сайт с короткими интерактивными занятиями английским для разработчиков.
- Целевая аудитория: разработчики с английским A2–B1. Первый курс — «Чтение документации»: короткие технические тексты, понимание смысла и повторение ошибок. Оценка эффективности обучения ещё не проводилась.
- Проект нужен для портфолио Python backend уровня middle и должен быть доступен для самостоятельной демонстрации.
- Разработка проекта служит обучению пользователя backend-разработке и подготовке к собеседованиям. Приоритет — наиболее распространённые, мейнстримные и актуальные технологии, подходящие задаче. Решения должны быть понятны пользователю и объяснимы на собеседовании.
- Функциональность и архитектура остаются лаконичными и уместными. Не добавляем функции, зависимости и инфраструктуру только ради технологии или демонстрации её наличия.
- Backend-фреймворк — FastAPI, выбран пользователем 2026-11-11. БД, фронтенд и оставшиеся компоненты стека ещё согласуем.
- Пользователь делегировал агенту языковую и методическую часть в рамках согласованного этапа: формулировки, нормализацию слов, подбор рекомендаций и пограничные случаи определяем самостоятельно, без отдельных вопросов по каждой детали. Существенные технические решения и расширение объёма по-прежнему согласуются целиком.
- Финансовая сверка отменена; прежние требования сохранены в docs/archive/financial-reconciliation.
- Существующие Python 3.13, инструменты разработки и CI сохраняем.

## Согласованный первый сценарий: онбординг

- До уроков пользователь проходит короткий адаптивный подбор стартовой сложности.
- Начинаем с простого текста; пользователь отмечает незнакомые слова. При малом числе незнакомых слов сложность следующего текста повышается.
- Если уже первый текст оказался сложным, показываем ещё один, более простой, для уточнения результата — пользователь подтвердил этот вариант.
- Максимум четыре текста, включая уточняющий. Если первый текст трудный, после более простого уточнения завершаем подбор: всего два текста. Если трудность возникла позже, рекомендуем последний успешно пройденный уровень. Если уточняющий текст тоже трудный — самый начальный маршрут.
- Согласованный начальный порог: не больше 20% незнакомых учитываемых слов — переход к более сложному тексту; больше 20% — текст трудный. Порог настраиваемый и пока не проверен на пользователях.
- В пределах текста повторяющееся слово учитываем один раз. Пунктуацию, числа и имена функций не считаем. По поручению пользователя агент определил нормализацию surface-v1 и контрольные количества слов; см. docs/onboarding-content.md.
- Для продолжения пользователь отмечает незнакомые слова либо явно выбирает «Все слова знакомы». Пустой неотправленный ответ не считается успешным.
- Самоотметка слов даёт сигнал о знакомстве с лексикой; не представляем её как достоверную сертификацию A2/B1. Результат формулируем как рекомендацию «Рекомендуем начать с…», сложность можно изменить.

- Онбординг доступен без регистрации. Создание аккаунта предлагаем после результата для сохранения прогресса. Уже полученный результат не должен требовать повторного прохождения после регистрации; техническое связывание с аккаунтом определим в дизайне.

## Подтверждено 2026-11-11: границы первого этапа

- Все пять авторских текстов приняты как версия 1; их можно менять по результатам проверки. См. docs/onboarding-content.md.
- Внутренние названия рекомендаций: «Основы», «Базовая документация», «Уверенное чтение», «Сложные тексты». Это не присвоение CEFR.
- После результата предлагаем регистрацию для сохранения рекомендации. Можно отказаться и остаться на экране результата. Учебные уроки добавляются следующим этапом; полный курс сейчас не требуется.
- Карта соответствия результатов текстов четырём рекомендациям определена агентом по поручению пользователя: все шесть конечных маршрутов описаны в docs/onboarding-content.md и docs/design.md. Это проектные правила, ещё не проверенные на учебной аудитории.

## Последующий учебный цикл: предложение

Первый учебный цикл: регистрация → короткий урок → проверка ответов с объяснениями → сохранение прогресса → повторение ошибок. Кабинет ученика и редактор заданий. Это ещё не утверждённый объём.

## Открытые вопросы

- Конкретные задания, правила проверки ответов и результат первого курса.
- Общее согласование технического дизайна, включая сохранение результата, регистрацию и оставшиеся компоненты стека. Языковые детали больше не требуют отдельных согласований.
- Размер демонстрационного курса и источник проверенного контента.
- Объём последующих этапов, интерфейс, оставшиеся компоненты стека и размещение.

Бизнес-логика обучения ещё не реализована. Рейтинги, интервальные повторения, серии занятий, уведомления и ИИ не включены автоматически.
