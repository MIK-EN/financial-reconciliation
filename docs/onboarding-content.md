# Тексты онбординга — версия 1

Согласованы пользователем 2026-11-11. Авторские примеры, не цитаты из документации библиотек и не валидированный CEFR-тест. На экране показываем английский текст и инструкцию «Нажмите на слова, которые вам незнакомы»; поясняющие названия ниже служат для работы над контентом.

## Упрощённый

Open the file. Read the text. Save your changes.

## Стартовый

You can create a new file, save your work, and open the file again later.

## Установка

Before you install the application, check the system requirements. You may need to update your operating system or free up some disk space.

## Параметры

The function returns a list of matching items. If you omit the optional limit parameter, it returns all available results. An empty list means that no matches were found.

## Ограничения

When a request fails, the client retries it automatically unless retries have been disabled. Repeated requests may cause duplicate operations, so this behavior should only be enabled when the server can safely handle them.

## Результат

Названия рекомендаций: «Основы», «Базовая документация», «Уверенное чтение», «Сложные тексты». Можно изменить выбранную сложность. После результата — предложение регистрации; отказ оставляет пользователя на результате. Уроков в первом этапе нет.

## Методические решения версии 1

2026-11-11 пользователь делегировал агенту языковые и методические детали. Правила ниже определены агентом в рамках этого поручения; они не являются результатом педагогического эксперимента. Пять согласованных английских текстов сохранены без изменений.

### Что измеряем

Отмечаем субъективную знакомость слов в данном контексте. Не проверяем понимание текста, владение грамматикой, произношение или способность писать. Знакомые слова не гарантируют понимание предложения. Поэтому результат — изменяемая рекомендация старта, а не оценка CEFR или экзаменационный балл.

Это ограничение согласуется с тем, что CEFR описывает несколько видов речевой деятельности, а знание слова включает форму, значение и употребление. Источники: [Совет Европы, сетка самооценки](https://www.coe.int/en/web/portfolio/self-assessment-grid), [Nation, Knowing a word, Cambridge University Press](https://www.cambridge.org/core/books/abs/learning-vocabulary-in-another-language/knowing-a-word/A663820BEC148D495A5B56E923CE3C37). Эти источники не валидируют наш порог 20% или конкретный алгоритм.

Порядок текстов — редакторская гипотеза: простые команды → знакомые действия с файлом → подготовка к установке → условие и необязательный параметр → исключение, пассивные конструкции и ограничения повторных запросов. Он ещё не откалиброван на пользователях A2–B1. Самый сложный текст намеренно проверяет верхнюю границу, но прохождение не присваивает более высокий CEFR.

### Нормализация и единица подсчёта

- Считаем уникальные написания внутри одного текста без учёта регистра: `File` и `file` — одна единица. Повтор слова в другом тексте считается заново.
- Разные формы считаем отдельно: `request` и `requests`, `return` и `returns`. Лемматизацию, стемминг и автоматическое объединение семейств слов не используем. Это воспроизводимое правило для самоотметки конкретных форм, а не утверждение об их педагогической независимости.
- Все обычные английские слова, включая `a`, `the`, `to`, участвуют в знаменателе. Стоп-слова не исключаем.
- В текстовых сегментах английская словоформа задаётся буквами A–Z/a–z с внутренним апострофом между буквенными группами. Прямой и типографский апостроф нормализуем к `'`; `don't` — одно написание. Кавычки по краям и пунктуация не входят в слово; дефис разделяет слова.
- Числа, URL, буквенно-цифровые идентификаторы и код не превращаем в частичные слова. Автор явно помечает такие сегменты как неучитываемые; публикационная проверка отклоняет непомеченные подобные фрагменты. Имена функций исключаются разметкой, а не угадыванием по английскому словарю.
- В пяти текстах v1 все английские словоформы учитываемые; `function` и `limit` — обычные технические слова в авторском описании, а не имена функций. Исключаемых кодовых сегментов в v1 нет.
- `free up` и другие сочетания считаем по словам. Инструкция разрешает отметить все слова непонятного выражения. Ограничение: такая самоотметка не измеряет знание устойчивых сочетаний отдельно.
- Все вхождения одного нормализованного слова выделяются и снимаются вместе. В API передаётся один ID слова, а не позиции его повторов. На экране сохраняются исходные регистр, пробелы и пунктуация.
- Для публикации обязательны непустой набор учитываемых слов и стабильные ID в пределах версии текста. Неожиданную письменность/разметку отвергаем при публикации; не считаем её молча по случайной эвристике.

### Порог и контрольные числа

`N` — количество уникальных учитываемых слов; `U` — количество отмеченных уникальных слов. Текст условно доступен, когда `100 × U ≤ 20 × N`. Сравнение целочисленное, без округления процентов; при равенстве повышаем сложность. Пустой неотправленный выбор не является ответом.

| ID текста | Название | Всего словоупотреблений | Уникальных N | Доступен при U | Трудный при U |
| --- | --- | ---: | ---: | --- | --- |
| `simplified` | Упрощённый | 9 | 8 | 0–1 | 2–8 |
| `start` | Стартовый | 15 | 14 | 0–2 | 3–14 |
| `installation` | Установка | 23 | 20 | 0–4 | 5–20 |
| `parameters` | Параметры | 29 | 26 | 0–5 | 6–26 |
| `constraints` | Ограничения | 34 | 31 | 0–6 | 7–31 |

Порог особенно груб на коротком тексте: 1 из 8 — 12,5%, 2 из 8 — 25%. Принимаем эту дискретность как ограничение первой версии. Не трактуем 20% неизвестных уникальных написаний как известный из исследований порог лексического покрытия текста: единицы подсчёта и назначение отличаются.

### Полная таблица переходов

| Текущий текст | Доступен | Трудный |
| --- | --- | --- |
| `start` | Показать `installation` | Показать `simplified` |
| `simplified` | Завершить: `foundations`, причина `simplified_accessible` | Завершить: `foundations`, причина `simplified_difficult` |
| `installation` | Показать `parameters` | Завершить: `foundations`, причина `start_accessible` |
| `parameters` | Показать `constraints` | Завершить: `basic_docs`, причина `installation_accessible` |
| `constraints` | Завершить: `complex_texts`, причина `constraints_accessible` | Завершить: `confident_reading`, причина `parameters_accessible` |

Всего шесть конечных маршрутов длиной 2, 2, 2, 3, 4 и 4 текста. Уточняющий текст никогда не возвращает на основную лестницу. Успешный старт соответствует «Основам», установка — «Базовой документации», параметры — «Уверенному чтению», ограничения — «Сложным текстам». Успех уточняющего и отсутствие успешных текстов также дают «Основы»: это самый начальный из четырёх маршрутов. Различие сохраняем в причине результата и пояснении, не вводя пятый уровень.

### Значение четырёх рекомендаций

Описания обозначают будущий учебный фокус; в текущей версии учебные модули ещё недоступны.

| ID | Название | Описание на экране |
| --- | --- | --- |
| `foundations` | Основы | Простые команды и частые слова о файлах, тексте и действиях. |
| `basic_docs` | Базовая документация | Короткие инструкции по установке, требованиям и настройке. |
| `confident_reading` | Уверенное чтение | Описания параметров, результатов и условий работы. |
| `complex_texts` | Сложные тексты | Исключения, ограничения и последствия действий в техническом тексте. |

### Тексты интерфейса

**Старт:** «Подберём стартовую сложность». Пояснение: «Вы увидите от двух до четырёх коротких текстов. Отметьте слова, значение которых вам непонятно в этом контексте. Это поможет предложить, с чего начать. Регистрация не нужна». Кнопка «Начать».

**Шаг:** «Нажмите на слова, которые вам незнакомы». Дополнение: «Если непонятно выражение целиком, отметьте слова этого выражения. Повторяющееся слово отмечается сразу во всём тексте». Для самостоятельного подбора рекомендуем отвечать без переводчика; это рекомендация, а не техническое ограничение.

**Ответ:** при отметках — «Продолжить»; без отметок — отдельное явное действие «Все слова знакомы». До отправки отметки можно менять. «Текст 2» обозначает текущий шаг; не показываем ложное «2 из 4», поскольку маршрут может завершиться раньше.

**Общий результат:** «Рекомендуем начать с: {название}». Подпись: «Это ориентир по отмеченным словам, а не оценка уровня английского. Вы можете выбрать другую сложность».

**Пояснения причин:**

- `simplified_accessible`: «В коротком тексте о действиях с файлом знакомых слов оказалось больше. Начнём с простых команд и частой лексики».
- `simplified_difficult`: «Даже в самом коротком тексте осталось несколько незнакомых слов. Предлагаем начать с простых команд и частой лексики».
- `start_accessible`: «Начальный текст оказался доступнее инструкции по установке. Предлагаем укрепить базовую лексику».
- `installation_accessible`: «Слова в инструкции по установке в основном знакомы. Предлагаем начать с коротких инструкций и настроек».
- `parameters_accessible`: «Слова в описании параметров в основном знакомы. Предлагаем начать с условий работы и результатов».
- `constraints_accessible`: «В самом сложном тексте вы отметили немного незнакомых слов. Можно начать с исключений и ограничений».

**Выбор:** «Выбранная сложность: {название}», действие «Изменить сложность». Исходная рекомендация остаётся видна и не переписывается выбором пользователя. После изменения: «Вы выбрали: {название}».

**Регистрация:** «Создайте аккаунт, чтобы сохранить рекомендацию и выбранную сложность». Действия «Создать аккаунт», «Уже есть аккаунт», «Пока не сейчас». Честное пояснение: «Учебные уроки появятся на следующем этапе. Сейчас доступен подбор сложности». После сохранения: «Рекомендация сохранена»; отказ оставляет на результате.

**Ошибка отправки:** «Не удалось подтвердить сохранение ответа. Попробуйте ещё раз». Не утверждаем, что ответ точно не сохранён: сервер мог завершить запись до обрыва связи. **Истечение:** «Срок хранения этого прохождения без аккаунта истёк. Можно начать заново».

### Проверка содержания и пределы готовности

Проведена редакторская проверка грамматики, связности и роста языковой сложности. Тексты — вымышленные технические ситуации: описание функции не относится к конкретной библиотеке, а повторные запросы не обещают безопасность любого реального API. Согласованные формулировки v1 не менялись.

Контрольные количества слов пересчитаны локально. Педагогической валидации и проверки интерфейса с пользователями ещё не было. В следующем учебном этапе потребуется проверять понимание смысла отдельными заданиями; такие задания не добавляются в текущий онбординг. При будущей проверке наблюдаем понятность инструкции, случаи непонимания при знакомых словах и изменение рекомендации пользователем; не выдаём эти наблюдения за доказанную эффективность обучения.
