# Состояние проекта

Обновлено: 2026-11-10.

## Подтверждено пользователем

- Цель: портфолио для собеседований на Python backend уровня middle.
- Предметная область: сверка финансовых операций.
- Версия языка: Python 3.13. Платформа репозитория: GitHub.
- Создан публичный репозиторий: https://github.com/MIK-EN/financial-reconciliation. Он пустой; локальные документы ещё не опубликованы. GitHub CLI авторизован как `MIK-EN`, протокол Git — SSH. Доступ к системному хранилищу учётных данных требует запуска вне песочницы; сообщение о недействительном токене внутри песочницы не подтверждает проблему авторизации.
- Пользователь согласовал личную доску процесса разработки и обязательное ведение Notion всеми чатами. Созданы страница https://www.notion.so/4148e5d0d65e8151afe8e422de330984 и база задач https://www.notion.so/a6dff3bfa4044a89a45f8458ab5805e3 с первыми карточками и доской статусов.
- Первый объём: файловая сверка, без интеграции с платёжным провайдером и без его имитатора.
- Правила совместной работы должны храниться в корневом `AGENTS.md` и использоваться из разных чатов.
- Не добавляем ИИ-ассистентов в авторы и соавторы, не используем их названия в ветках и других метаданных, не добавляем автоматические подписи об ИИ.
